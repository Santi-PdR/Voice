# Changelog

## 1.2.0 - Self-managed offline Rafael voice

### Core architecture

- Made Piper offline TTS the default voice path.
- No API key, paid account, Python backend, localhost service or persistent terminal is required.
- Added automatic platform detection for Windows x64, Linux x64/ARM64 and macOS x64/ARM64.
- Added automatic first-use Piper runtime + `es_AR-daniela-high` model installation.
- Added persistent runtime/model cache and pinned SHA-256 validation of the voice model.
- Added safe ZIP/TAR.GZ extraction with path traversal protection and Linux/macOS symlink handling.
- Added asynchronous server-start voice prewarming.
- Cloud TTS providers now degrade automatically to offline voice when unconfigured or unavailable.

### Rafael brain

- Added a stronger deterministic local analytical brain so external AI is optional.
- Added local manual diagnostics for system state, health, dimension and immediate risk.
- Added friendly dimension naming.
- Added critical hunger threshold reactions.
- Added dimension-transition reactions.
- Preserved death, respawn, health, gamemode, advancement and optional item-drop analysis.
- Manual test/voice commands now respect normal anti-spam cooldowns.

### Audio and presentation

- Added configurable client-side acoustic aura to reduce flat TTS character without changing speech pitch/duration.
- Added layered activation cue using enchantment + amethyst signatures.
- Increased server audio cache from 32 to 48 entries.
- Refined offline Piper cadence/noise defaults for a calmer, more controlled feminine system voice.

### Operations and documentation

- Added `/rafael prepare`.
- `/rafael status` now reports local brain and offline voice preparation state.
- Reworked voice setup documentation around zero-key operation.
- Added third-party notices for Piper and the Daniela voice dataset.
- Version bumped to 1.2.0.

## 1.1.0 - Server-native voice architecture

- Removed the required Python/FastAPI/FFmpeg/localhost runtime backend.
- Network protocol upgraded from v1 to v2.
- Voice generated by the Forge server and transmitted to clients as bounded WAV bytes.
- Added optional OpenAI/ElevenLabs providers, per-player cooldowns, improved HUD/audio, GitHub Actions and security documentation.
