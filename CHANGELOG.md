# Changelog

## 1.1.0 - Server-native voice architecture

### Breaking runtime changes

- Removed the required Python/FastAPI/FFmpeg/localhost runtime backend.
- Network protocol upgraded from v1 to v2.
- Voice is generated by the Forge server and transmitted to clients as bounded WAV bytes.

### Added

- Direct OpenAI Responses support for concise contextual Rafael analysis.
- Direct OpenAI `gpt-4o-mini-tts` WAV synthesis.
- Optional ElevenLabs PCM TTS provider with Voice ID support.
- Server-only secret handling with environment-variable fallback.
- TTS cache, provider timeouts, response size caps and packet size caps.
- `/rafael voice` and truthful `/rafael status` diagnostics.
- Config toggles for every major automatic event.
- Per-player/per-event cooldown protection.
- Synthetic voice indicator in the HUD.
- GitHub Actions Java 17 / Gradle 8.3 build workflow.
- Security and voice setup documentation.

### Improved

- Safe server-thread snapshot/delivery flow around asynchronous provider work.
- Audio overlap handling and Java Sound diagnostics.
- HUD scaling, fading, wrapping, line limits, particles, rings, rays and emotion accents.
- Separate generated-voice and UI-sound volume controls.
- Item-drop chatter disabled by default due to noise.

### Removed

- Client-side HTTP audio downloads.
- Runtime dependency on `ai_backend/main.py` and `requirements.txt`.
